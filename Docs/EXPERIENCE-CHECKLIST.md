## 一、Markdown 笔记（10 分钟）

这是 DeskMate 的基本盘，值得认真写一篇。

| # | 试什么 | 怎么试 | 期望结果 |
|---|---|---|---|
| 1.1 | **三种视图** | 新建笔记 → 右上角切「编辑 / 分栏 / 预览」 | 三个视图切换流畅，记住你的选择 |
| 1.2 | **GFM 语法** | 输入 `# 标题`、`**粗体**`、`- 列表`、`> 引用`、`` `代码` ``、表格、`~~删除线~~` | 预览区正确渲染（GitHub Flavored Markdown） |
| 1.3 | **任务列表** | 输入 `- [ ] 待办` 和 `- [x] 完成` | 预览里出现可勾选的复选框 |
| 1.4 | **告警块** | 输入 `> [!WARNING]` 之类 | 渲染成带颜色的提示块 |
| 1.5 | **分栏同步滚动** | 设置 → 勾「分栏同步滚动」→ 在左侧滚动 | 右侧预览跟随滚动位置 |
| 1.6 | **图片粘贴** | 直接 Ctrl+V 粘贴一张截图 | 图片内嵌进笔记，不变成外部链接 |
| 1.7 | **字号与缩进** | 设置 → 编辑器字号、Tab 缩进宽度 | 立即生效，改完不用重启 |
| 1.8 | **HTML 开关** | 设置 → 「允许 HTML 标签渲染」开/关 | 关掉时 `<b>` 这类标签按纯文本显示 |
| 1.9 | **导入导出** | 笔记右键 → 导出 `.md`；再导入回来 | 往返不丢内容、格式不乱 |
| 1.10 | **背景图** | 设置 → 背景图片 → 选择/清除，调遮罩、缩放、模糊 | 背景按设置生效；「填充/完整/平铺」三种适配都对 |

## 二、快捷便签与磁贴（5 分钟）

DeskMate 的差异点：**随时呼出、随手钉在桌面**。

| # | 试什么 | 怎么试 | 期望结果 |
|---|---|---|---|
| 2.1 | **快捷键呼出** | 默认 `Ctrl+Space`（可在设置改） | 任意应用前台都能弹出便签小窗 |
| 2.2 | **跟随鼠标** | 设置 → 「快捷键打开时跟随鼠标位置」 | 小窗出现在鼠标附近而不是屏幕中央 |

## 四、课程表（重点，10 分钟）

最容易「哇」一下的功能，尤其如果你有真实教务系统导出的课表文件。

| # | 试什么 | 怎么试 | 期望结果 |
|---|---|---|---|
| 4.1 | **导入课表文件** | 课程表 → 导入 → 选「课表文件」页签 → 教务系统导出的 `.xls` / `.xlsx`（≤10 MB）或打印出来的 `.pdf`（≤20 MB） | 自动识别表头、逐格拆分；导入前显示课程数、来源和**逐行预览**；无法解析的格子列为 warnings（「N 个单元格无法解析，可导入后手工补录」）。PDF 也能识别旋转 90° 的横向课表，跨页被切开的课程会拼回一门 |
| 4.2 | **单双周与地点变更** | 导入后看 `1-8,10-16周`、`单周`、`双周` 的课程 | 周次和地点都正确；同课程同星期的多行会合并周次 |
| 4.3 | **文字粘贴** | 导入对话框切到「文字粘贴」页签，粘贴一段课表文字（每行一门、字段顺序不限） | 也能识别「周一 / 星期三 / Mon」「1-2节 / 第5节」「@教室」「张老师」等写法；点「插入示例」可看格式示例 |
| 4.4 | **手动加课** | 点网格空白处 | 新增课程：课程名、星期、起止节、地点、教师、周次、颜色、备注 |
| 4.5 | **学期与周次** | 课程表设置 → 填「学期开始日期」 | 顶部显示「第 N / 总周数」，侧栏显示当前周；能切「仅本周」过滤 |
| 4.6 | **每节时刻** | 课程表设置 → 逐节配置起止时间 | 自定义后网格显示的时刻跟着变；可一键恢复默认 |
| 4.7 | **调课与停课** | 给某课加一条「某天停课 / 调至其他节次」 | 课程块显示「停课/调课」标记；排期与周统计都会应用 |
| 4.8 | **课程作业** | 课程抽屉 → 添加作业/待办/提醒 | 课程块右上角显示未完成数量；该作业同时出现在「今天/本周/逾期」清单里 |
| 4.9 | **课程笔记归档** | 课程抽屉 → 「记笔记」 | 自动生成「第 N 周 · 课程名」笔记，分类为课程名，正文带日期/地点/教师/周次，并直接打开编辑器 |
| 4.10 | **A4 打印** | 课程表 → 打印 | 白底 A4 横向视图，应用 UI 自动隐藏，可直接打印或另存 PDF |
| 4.11 | **周回顾** | 课程模式 → 周回顾 | 汇总本周上课时长、日程时长、完成待办数、每日必做完成率与各课程未完成作业，写入「每周回顾」分类笔记 |
| 4.12 | **DDL 压力条** | 待办列表顶部 | 未来 14 天每天到期的未完成数柱状条，逾期单独计数，峰值日高亮 |

## 值得专门吐槽几句的地方

如果你想给反馈，下面这些最容易出问题的点请重点试：

1. **课表导入的边界** —— 教务系统导出的表格格式千奇百怪，试试不同学校的 `.xls` 和打印版 `.pdf`，看解析器会不会漏字段、把多门课挤进一格、或把周次解析错。
2. **智能排期的空档计算** —— 加一门早课、或者加一个长日程，看看 08:00–22:00 的空档算得对不对、课程后 5 分钟缓冲准不准。
3. **提醒的边界时刻** —— 设一个「正好在免打扰时段开始」「正好在上课中」「刚好跨过上课结束」的提醒，看静默和补发是否符合直觉。
4. **双人课表的重叠** —— 造几门时间重叠的课（包括跨节次、不连续的节次），看双方课程是否都能读全、共同空档是否算对。
5. **跨天/跨周行为** —— 待办跨天、每日必做跨天重置、学期周次推进、回顾笔记跨天生成，这些「时间边界」最容易藏 bug。
